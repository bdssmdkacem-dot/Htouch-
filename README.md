# DTOUCH
تحكّم بشاشة أندرويد بإيماءات اليد عبر الكاميرا الأمامية (Kotlin + CameraX + MediaPipe + AccessibilityService).

## بناء الـ APK من GitHub
1. أنشئ مستودعًا جديدًا وارفع محتوى هذا المجلد كما هو (مع مجلد .github).
2. افتح تبويب Actions ثم "Build DTOUCH APK" ثم Run workflow (أو يعمل تلقائيًا عند push).
3. بعد انتهاء البناء حمّل Artifact باسم DTOUCH-apk ثم فك الضغط وثبّت app-debug.apk.

## التشغيل على الهاتف
1. افتح التطبيق واضغط "تفعيل خدمة إمكانية الوصول" ثم فعّل DTOUCH.
   - أندرويد 13+: إن كان الخيار رماديًا، افتح معلومات التطبيق ثم القائمة (⋮) ثم "السماح بالإعدادات المقيّدة" وارجع.
2. اضغط "تشغيل DTOUCH" وامنح صلاحية الكاميرا والإشعارات.
3. ضع يدك أمام الكاميرا الأمامية (إضاءة جيدة، مسافة 30-50 سم).
